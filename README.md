
# SIRKEL
## The easy organization tool that rocks.

This tool is intended to be easy to use. It's used to create virtuous circles. That's why... sirkel.

The characters in this opera are:

#### Project
The big picture.

#### Goal
One of the objectives of the project.

#### Task
One of the things we have to achieve to reach the goal.

#### Task Item
The pieces to ensemble the task puzzle.

## States
Each of the characters have a state that will be moved eighter by the user or by the system.

Project
- planning
- active
- on-hold
- completed
- archived

Goal
- active
- achieved
- on-hold
- abandoned

Task
- todo
- in-progress
- blocked
- done
- cancelled
- in-review

TaskItem
- pending (to-do)
- in-progress
- done
- cancelled
